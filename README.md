# Piggyback Pros — Live Demo

A modern, responsive website for **Piggyback Pros**, featuring a clean user experience across desktop, tablet, and mobile devices.

This project is a **Live Demo** of the website.

## Features

- Responsive design for desktop, tablet, and mobile
- Modern navigation and layout
- Truck-mounted forklift repair and service information
- Service and maintenance sections
- Contact form
- Diagnostic/service request form
- File upload support
- Digital signature functionality
- Mobile-friendly interactions
- Live Demo badge
- Favicon and Apple touch icon support

## Technologies

- HTML5
- Tailwind CSS
- Vanilla JavaScript
- HTML5 Canvas
- Netlify Forms
- Netlify configuration

## Deployment

The project is a static website and can be deployed through GitHub Pages or Netlify.

For **GitHub Pages**, keep `index.html` and all assets (`logo.png`, `favicon.ico`, `apple-touch-icon.png`, etc.) in the repository root when publishing from `main` → `/ (root)`.

Asset paths are relative so they work correctly when the repository is served from a GitHub Pages project URL.

For **Netlify**, keep the included `netlify.toml` and `__forms.html` files.

## Important Notes

- The diagnostic service uses the site's own service request form; **no Jobber form/embed is included in this version**.
- Do not add passwords, API keys, database credentials, or other private secrets to frontend files.
- Tailwind CSS is loaded through the CDN.
- Netlify form handling requires Netlify deployment.
